# Provecta EU — Detailed (FR, DE, UK, IT, ES)

> Standalone detailed dashboard. Living document — update after every change.

## What this is

A **4-tab standalone** for the Provecta pest-control category across 5 EU Amazon
markets (FR / DE / UK / IT / ES, ordered by market size). ALL static UI text is
in **POLISH** (same as `atopic-skin-detailed`; an English variant was built first
on 2026-07-08 and reverted the same day on Tom's correction). There is **NO
segment dimension** — navigation is by country pills only (the key difference vs
`atopic-skin-detailed`, which this dashboard is architecturally cloned from).

| Tab | Label | Source |
|-----|-------|--------|
| 1 | `Rynek` | Cross-market topline generated by `_build_rynek.py` (markets-only, Polish rework of the atopic Rynek tab) |
| 2 | `Struktura rynku` | Per country, `renderMarketStructure(bucket)` — local Polish template (atopic copy), single-segment mode ("Cały rynek" pseudo-segment, sub-tab row hidden when 1 segment) |
| 3 | `Recenzje (VOC)` | Per country, `renderReviews(bucket)` — Console `u-reviews-voc` template + Polish KPI patch (headline from X-Ray, star bar hidden) + `VOC_STR` chrome translations |
| 4 | `Marketing Deep-Dive` | Per country, `renderMarketingDeepDive(bucket)` — local template (verbatim atopic szelki-style MDD, Polish) + `MDD_STR` chrome translations |

- **Tab 1 has NO pills** — whole cross-market view. Tabs 2–4 show one country pill row (`Francja 🇫🇷 · Niemcy 🇩🇪 · Wielka Brytania 🇬🇧 · Włochy 🇮🇹 · Hiszpania 🇪🇸`).
- Navigation state is `{ tab, country }`; a single dynamic panel per tab re-renders on change.
- UK is a full member of every tab (VOC + MDD data exist for all 5 markets).

**Projections:** 12M = 30d × 12 flat (no per-ASIN sales history exists for this
category). units30d = ASIN Revenue ÷ price. UK £→€ at **1.195** (ECB Mar 2026)
for all cross-market EUR aggregates; UK product prices shown in £ in per-market
tables. Sanity anchor: total ≈ €16.2M / ~1.06M units 12M (matches the standalone
`Dashboards/Provecta EU` topline built from the same files).

## Known data caveats

- **UK reviews scrape contains ONLY 4–5★ reviews** (123 total, zero negatives).
  UK `_qual.json` derives "negative topics" from criticisms inside positive
  reviews and says so explicitly. Re-scrape UK with negatives to fix properly.
- Scraped review star distributions are critical-skewed everywhere (e.g. IT avg
  2.31 vs X-Ray 4.22) → headline avg rating + product count come **from X-Ray**
  (weighted by review count); star-distribution bar is hidden (same decision as
  atopic-skin-detailed).

## Build pipelines

```
python voc_pipeline.py prep {CODE}      # reviews.csv -> _analysis_input.json (stats + <=120 sample, ORIGINAL language)
<LLM writes reviews/{CODE}/_qual.json>  # POLISH qualitative block (schema = atopic _qual.json)
python voc_pipeline.py assemble {CODE}  # -> voc.json (ALL reviews original-language, multilingual pest-theme tagging, Polish theme labels)

python fetch_listings.py ALL            # SP-API Catalog (EU endpoint incl. UK marketplace A1F83G8C2ARO7P), top-14/market
python mdd_pipeline.py ALL              # deterministic: claims regex (DE/FR/IT/ES/EN stems), adoption, VOC gap, whitespace -> mdd.json

python _build_standalone.py             # runs _build_rynek.py first, assembles index.html (~2 MB)
```

- Pest claim THEMES (13, Polish labels + Polish VOC-gap stems) live in
  `mdd_pipeline.py`; browser review-tagging themes (14, Polish labels) in
  `voc_pipeline.py`. Both use multilingual keyword stems (DE/FR/IT/ES/EN) —
  extend stems there when tagging misses grow.
- The VOC renderer is patched at build time (`VOC_PATCH` in `_build_standalone.py`):
  KPI row rewritten (Polish) to X-Ray headline + star bar removed. The patch
  anchors are verbatim template code — if Console `u-reviews-voc/template.html`
  changes, the build fails loudly with "VOC patch anchor not found". Then
  `VOC_STR` / `MDD_STR` translate the remaining English chrome (copied from
  atopic's tables; tolerant, missing anchors are skipped).
- `templates/tabs/` here are VERBATIM copies of the atopic-local Polish templates;
  market-structure additionally has single-segment mode (pill row skipped when
  `segments.length === 1`).

## Rebuild

```
python dashboards/provecta-eu-detailed/_build_standalone.py
```
Writes `index.html` next to the script. Prints per-country VOC/MDD/structure coverage.

## Hub registration

Central `config.json` entry (group `detailed`, template `standalone`), placed
right after `atopic-skin-detailed`. Deploy: `git push origin master:main`.

## Key decisions / gotchas

- **POLISH UI is Tom's explicit requirement** (2026-07-08: "ale ma być po polsku").
  Do not flip to English; the English tab names in the original brief were
  descriptive, not a language choice.
- `XRAY_LINKS` in `_build_standalone.py` are all `'#'` placeholders — header
  buttons render only for non-`'#'` entries, so none show yet. Add Google Sheet
  URLs there when the sheets exist.
- Chart instances with canvas ids `ms*` are destroyed before every Market
  Structure re-render (stale-canvas guard, same as atopic).
- House style: build normalizes ALL em/en dashes to plain hyphens in the final HTML.
