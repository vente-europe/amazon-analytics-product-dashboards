# Reference products — calibration for `Irritated / Atopic` segment

Tom-supplied descriptions (PL) of ~8 reference shampoos that DEFINE the segment. Use these to decide whether a DE X-Ray shampoo belongs to `Irritated / Atopic`. Match on **meaning/claims**, not literal words (reference = PL, listings = DE).

## Qualifying signals (a shampoo is `Irritated / Atopic` if its title/bullets express ≥1 of these)

**Conditions addressed:**
- sensitive / hypersensitive scalp — *wrażliwa / nadwrażliwa* — DE: `empfindliche / sensible Kopfhaut`
- dry scalp — *sucha* — DE: `trockene Kopfhaut`
- irritated / prone to irritation — *podrażniona / skłonna do podrażnień* — DE: `gereizte / zu Reizungen neigende`
- itchy / itch — *swędząca / świąd* — DE: `juckende / Juckreiz`
- atopic / atopic dermatitis (AZS) — DE: `atopisch / Neurodermitis`
- eczema / psoriasis — *egzema / łuszczyca* — DE: `Ekzem / Schuppenflechte / Psoriasis`
- seborrhea / cradle cap — *łojotok / ciemieniucha* — DE: `seborrhoisch / Kopfgneis`

**Product character (supporting signals):**
- hypoallergenic, allergy/derma-tested — *hipoalergiczny, testowano alergologicznie/dermatologicznie* — DE: `hypoallergen / allergiegetestet / dermatologisch getestet`
- soothing / calming — *koi / łagodzi* — DE: `beruhigend / kopfhautberuhigend`
- gentle / mild, for frequent use — *delikatny / łagodny, do częstego stosowania* — DE: `mild / sanft / für häufige Anwendung`
- fragrance-free / no preservatives/dyes — DE: `parfümfrei / ohne Duftstoffe / ohne Konservierungsstoffe`
- for children / babies / whole family — *dla dzieci / niemowląt / całej rodziny* — DE: `für Kinder / Babys / die ganze Familie / ab dem 1. Lebensmonat`
- supports skin barrier, moisturizing/emollient — DE: `Hautbarriere / Feuchtigkeit / Emoliens`
- medical device / dermatological — *wyrób medyczny / dermatologiczny*
- active ingredients: Urea/mocznik, Polidocanol/polidokanol, NMF, Ichthyol/ichtiol, Betaine

## NOT the segment (exclude from `Irritated / Atopic`, even if a shampoo)
- Purely cosmetic shampoos: volumizing, colour/silver, anti-hair-loss, repair/shine, oily-hair styling — with **no** sensitive/irritated/atopic/soothing framing.
- **Pure cosmetic anti-dandruff** (anti-Schuppen) with no sensitive/dry/soothing/dermatological angle → borderline; flag for Tom rather than auto-tag.
